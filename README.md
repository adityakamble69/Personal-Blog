## ⚡ Setup & Local Development

### **Prerequisites**
Make sure you have Node.js (v18+) and npm installed on your machine.

### **1. Clone the repository**
```bash
git clone https://github.com/adityakamble69/Personal-Portfolio.git
cd Personal-Portfolio
```

### **2. Install Dependencies**
```bash
npm install
```

### **3. Run Development Server**
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) with your browser to see the local version of your website.

### **4. Build for Production**
```bash
npm run build
```
